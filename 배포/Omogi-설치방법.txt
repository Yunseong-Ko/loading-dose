Omogi — 화면에 사는 작은 뱁새 (Mac 판, 테스트 버전 0.3.0)
제작자: @hi20010205

화면 아래에 흰오목눈이 "오모기"가 살면서 돌아다니고, 졸고, 둥지를 짓습니다.
친구와 쪽지를 주고받을 수 있는데, 오모기가 물고 날아가서 30분~3시간 뒤에 전해 줍니다. 가끔은 잃어버리기도 합니다.
의대생이라면 국시 대비 O/X 문제도 풀 수 있습니다 (기초과목 포함 25개 과목, 약 2,800문항).


설치

1. Omogi-Mac.zip 을 더블클릭해 압축을 풀고, 나온 Omogi 앱을 "응용 프로그램" 폴더로 옮깁니다.
2. Omogi 를 더블클릭합니다. "열 수 없습니다"라는 경고가 뜨면 "완료"를 누릅니다.
3. 시스템 설정 → 개인정보 보호 및 보안 → 맨 아래로 내려 "그래도 열기"를 누릅니다.
   (macOS 14 이하: Omogi 앱을 Control-클릭 → 열기)
4. 화면 아래에 오모기가 나타나고, 설정 창이 뜹니다.

설정과 메뉴를 여는 방법은 세 가지이고, 어느 것이든 같습니다.
 - Omogi 앱을 다시 엽니다 (응용 프로그램 폴더, Launchpad, Spotlight). 설정 창이 뜹니다.
 - 화면의 오모기를 오른쪽 클릭합니다 (또는 Control-클릭).
 - 화면 맨 위 메뉴 막대의 새 얼굴 아이콘을 누릅니다. 메뉴 막대에 아이콘이 많으면 가려져서 안 보일 수 있습니다.

3번에서 "그래도 열기"가 안 보이면 터미널에 아래 한 줄을 붙여넣고 다시 엽니다.
   xattr -dr com.apple.quarantine "/Applications/Omogi.app"

macOS 12 이상에서 동작합니다.


이미 깔아서 쓰던 분 (업데이트: 예전 버전 → 0.3.0)

1. 쓰던 Omogi 를 끕니다.
   - 설정 창이나 메뉴에서 "Omogi 종료". (오모기를 오른쪽 클릭해도 메뉴가 나옵니다.)
   - 0.1.0 이라 메뉴를 열 방법이 없으면: Spotlight(⌘+스페이스)에서 "활성 상태 보기"를 열고, 목록에서 Omogi 를 골라 위쪽 ⓧ 버튼 → 종료.
2. 새로 받은 Omogi 앱을 "응용 프로그램" 폴더로 옮기고, 물어보면 "대치"를 누릅니다.
3. 새 Omogi 를 엽니다. 처음 깔 때처럼 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기".
4. "Omogi 이(가) 키체인에 저장된 정보를 사용하려고 합니다"라는 창이 한두 번 뜹니다.
   Mac 로그인 암호를 넣고 꼭 "항상 허용"을 눌러 주세요. 이렇게 해야 아이디와 친구가 그대로 남습니다.
   ("거부"를 누르면 새 사람으로 시작하게 되어, 아이디를 다시 정하고 친구를 다시 맺어야 합니다.)
5. 집중 모드를 쓰고 있었다면 권한을 다시 줘야 합니다.
   시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → 목록의 Omogi 를 선택해 "−"로 지운 뒤, Omogi 설정 창에서 집중 모드를 껐다 켭니다.
   일정 알림도 캘린더 접근을 다시 물으면 허용해 주세요.

 - 받은 편지, 보낸 편지, 켜 둔 설정은 그대로 남습니다.
 - 0.2.0 에서 올라오는 분은 덮어쓰기만 하면 되고, 키체인 창도 뜨지 않습니다.
 - 4번의 키체인 창은 0.1.0, 0.1.1 에서 올라올 때만 한 번 뜹니다. 0.1.2 를 쓰던 분은 뜨지 않습니다.
 - 친구가 아직 예전 버전을 쓰고 있어도 편지는 서로 오갑니다.


O/X 문제 풀기  (기본은 꺼져 있습니다. 설정 창에서 켭니다)

 - 가끔 물어 오기: 컴퓨터를 쓰는 동안 25분쯤마다 오모기가 문제를 물고 옵니다. 오모기를 살짝 누르면 문제가 펼쳐집니다.
   한참 안 누르면 그냥 내려놓습니다. 권한이 필요 없습니다.
 - AI 답변을 기다리는 동안: Claude 나 ChatGPT 의 Mac 앱에서 질문을 쓰고 Enter 를 누르면, 답을 기다리는 동안 화면 위에 문제가 뜹니다.
   답이 도착하면 알아서 접힙니다. 켜면 "손쉬운 사용" 권한을 묻습니다.
   (브라우저에서 쓰는 claude.ai, chatgpt.com, Gemini 는 아직 안 됩니다.)
 - 지금 한 문제 풀기: 설정 창의 버튼을 누르면 바로 한 문제가 뜹니다.
 - 답하기: O / X 버튼을 누릅니다. AI 답변을 기다리는 동안 뜬 카드는 Option+O / Option+X 로도 됩니다.
 - 과목 고르기: 설정 창의 "O/X 과목 고르기…"에서 풀 과목만 켭니다.
 - 연속으로 맞히면 오모기가 점점 커집니다. 다섯 번 연속이면… 직접 해 보세요.
 - Loading Dose 를 같이 쓰고 있으면 "AI 답변을 기다리는 동안" 카드는 Loading Dose 쪽에서만 뜹니다.
 - 문항은 사람이 하나하나 검수한 것이 아닙니다. 틀린 곳이 보이면 알려 주세요.


꼬마 뱁새와 옷장  (0.3.0 에서 새로 생겼습니다)

 - O/X 문제를 맞히면 꼬마 뱁새가 1마리씩 모입니다. 틀려도 깎이지 않습니다.
 - 다섯 번 연속으로 맞혀 오모기가 펑 터지면 꼬마들이 흩어집니다. 날아가기 전에 눌러서 잡으면 그만큼 더 모입니다.
 - 하루에 60마리까지 모을 수 있습니다.
 - 설정 창이나 메뉴의 "옷장…"에서 모은 꼬마 뱁새로 옷을 사서 입힙니다.
   빨간 목도리, 밀짚모자, 동그란 안경, 수술모, 청진기, 학사모, 왕관이 있고, 머리·얼굴·목에 하나씩 입힐 수 있습니다.
 - 과목 배지는 살 수 없고, 한 과목에서 100문제를 맞히면 그 과목의 배지를 받습니다 (25개 과목, 색이 다릅니다).
 - Anki 빈칸 카드처럼 스스로 "알았음"을 누르는 카드는 세지 않습니다.
 - 꼬마 뱁새와 가진 옷은 내 컴퓨터에만 저장됩니다. 입은 옷은 마을에서 친구에게 보입니다.


마을, 공부 시작/끝, 콕 찌르기  (친구를 맺은 사람끼리)

 - 설정 창이나 메뉴의 "마을…"을 열면 친구들의 오모기가 입은 옷 그대로 모여 있습니다.
 - 친구마다 오늘 맞힌 문제 수, 오늘 공부한 시간, 지금 공부 중인지가 보입니다.
 - "공부 시작"을 누르면 내 오모기가 책을 보고, 친구의 마을에 "공부 중"으로 나옵니다.
   5분 넘게 손을 놓으면 저절로 멈추고, 그 시간은 공부 시간에서 뺍니다. 다시 하려면 "공부 시작"을 누릅니다.
 - 친구 옆의 "콕"을 누르면 내 옷을 입은 새가 친구 화면으로 날아가 인사하고 돌아옵니다.
   편지와 달리 1분 안쪽으로 도착합니다. 한 친구에게 하루 10번까지입니다.
 - 친구에게서 편지가 도착하면 그 친구의 새가 잠깐 들렀다 갑니다.
 - 친구에게 보이는 것: 입은 옷, 오늘 맞힌 문제 수, 오늘 공부 시간, 공부 중인지.
   오늘 맞힌 수는 마을 창의 "오늘 맞힌 수 보이기"를 끄면 숨겨집니다.
   이 정보는 편지와 달리 잠그지 않고 서버에 올라갑니다. 서로 친구가 된 사람에게만 보여 줍니다.
 - 친구를 맺지 않았다면 아무것도 올라가지 않습니다.


친구와 편지 주고받기

1. 설정 창(또는 메뉴)의 "친구…" → 이름과 아이디를 적고 "시작하기"를 누릅니다.
   아이디는 친구가 나를 찾을 때 쓰는 이름표입니다 (영문 소문자·숫자·밑줄 3~16자, 예: omogi_fan). 안 정해도 되고 나중에 바꿀 수 있습니다.
   아이디를 안 정하면 자동으로 만들어진 8자 친구 코드를 대신 씁니다.
2. 내 아이디(또는 코드)를 "복사"해서 친구에게 보내거나, 친구에게 받은 아이디를 입력하고 "친구 요청"을 누릅니다.
3. 요청을 받은 쪽이 "친구…" 창에서 "수락"을 누르면 친구가 됩니다.
4. "편지 쓰기…"에서 친구를 고르고 200자까지 씁니다. 오모기가 물고 날아갑니다.
5. 편지가 오면 오모기가 편지를 물고 돌아옵니다. 오모기를 살짝 누르면 편지함이 열립니다.

 - 언제 도착할지는 보낸 사람도 모릅니다 (30분~3시간).
 - 열 통에 한 통꼴로 오모기가 편지를 잃어버립니다. 잃어버리면 보낸 사람에게만 알려 줍니다.
 - 한 친구에게는 하루 5통까지 보낼 수 있습니다.
 - Mac 이 꺼져 있던 동안 온 편지는 다음에 켰을 때 도착합니다.
 - "나에게 (연습)"으로 보내면 혼자서도 어떻게 되는지 볼 수 있습니다.


그 밖에 할 수 있는 것  (설정 창이나 메뉴에서 켜고 끕니다)

 - 오모기를 집어서 다른 곳에 놓을 수 있습니다.
 - 습관 알림: 물 마시기, 눈 쉬기, 스트레칭을 때맞춰 알려 줍니다. (기본 켜짐)
 - 집중 모드: 브라우저에서 유튜브·인스타그램을 열면 오모기가 날아가 탭을 닫습니다. (기본 꺼짐)
   켜면 "손쉬운 사용" 권한을 묻습니다. 브라우저 창의 제목만 읽고, 어디에도 기록하거나 보내지 않습니다.
 - 일정 알림: Mac 캘린더의 일정이 시작하기 10분 전에 알려 줍니다. (기본 꺼짐, 켜면 캘린더 접근을 묻습니다)
 - 동작 보기: 오모기가 할 수 있는 동작을 하나씩 볼 수 있습니다.
 - 끄기: 설정 창의 "Omogi 종료"


터미널 한 줄로 하기  (업데이트·재설치)

"터미널" 앱을 열고 아래 한 줄을 통째로 붙여넣은 뒤 Enter 를 누릅니다.
쓰던 Omogi 를 끄고(응용 프로그램·다운로드 폴더 어디에 있든 지우고), 새 버전을 받아 응용 프로그램 폴더에 넣고 엽니다.
이 방법으로 받으면 "열 수 없습니다" 경고도 뜨지 않습니다.

[A] 업데이트 — 아이디, 친구, 편지, 설정은 그대로 둡니다.

pkill -x Omogi; rm -rf /Applications/Omogi.app ~/Downloads/Omogi.app; curl -L -o /tmp/Omogi-Mac.zip https://github.com/Yunseong-Ko/loading-dose/releases/download/omogi-v0.3.0/Omogi-Mac.zip && ditto -x -k /tmp/Omogi-Mac.zip /Applications && xattr -dr com.apple.quarantine /Applications/Omogi.app; open /Applications/Omogi.app

[B] 완전히 지우고 새로 — 아이디, 친구, 받은 편지, 설정이 모두 사라집니다.
    편지를 쓰고 있었다면 먼저 설정 창 → "친구…" → "서버에서 내 정보 지우기…"를 누르고 하세요.

pkill -x Omogi; rm -rf /Applications/Omogi.app ~/Downloads/Omogi.app ~/Library/Application\ Support/Omogi; defaults delete com.omogi.mac 2>/dev/null; curl -L -o /tmp/Omogi-Mac.zip https://github.com/Yunseong-Ko/loading-dose/releases/download/omogi-v0.3.0/Omogi-Mac.zip && ditto -x -k /tmp/Omogi-Mac.zip /Applications && xattr -dr com.apple.quarantine /Applications/Omogi.app; open /Applications/Omogi.app

 - 0.1.0, 0.1.1 에서 [A]로 올라오면 키체인 창이 한 번 뜹니다. Mac 암호를 넣고 "항상 허용"을 누르세요.
 - 집중 모드나 "AI 답변을 기다리는 동안"을 쓰고 있었다면 손쉬운 사용 권한을 지웠다가 다시 줘야 합니다 (위 5번).


완전히 지우고 새로 깔기  (손으로 하는 방법)

보통은 지울 필요 없이 위의 업데이트 방법대로 덮어쓰면 됩니다. 뭔가 꼬였거나 처음부터 다시 시작하고 싶을 때만 하세요.
이렇게 하면 아이디, 친구, 받은 편지가 모두 사라집니다.

1. (편지를 쓰고 있었다면) 설정 창 → "친구…" → 맨 아래 "서버에서 내 정보 지우기…"를 누릅니다.
   이걸 하지 않고 지우면 서버에 예전 아이디가 남아서 같은 아이디를 다시 쓸 수 없습니다.
2. Omogi 를 끕니다. (설정 창의 "Omogi 종료", 또는 "활성 상태 보기"에서 Omogi 종료)
3. "응용 프로그램" 폴더의 Omogi 를 휴지통에 버립니다.
4. 남은 자료를 지웁니다. Finder 에서 ⌘+Shift+G 를 누르고 아래 주소를 붙여넣은 뒤, 열린 Omogi 폴더를 휴지통에 버립니다.
      ~/Library/Application Support/Omogi
   터미널이 편하면 아래 두 줄로도 됩니다.
      rm -rf ~/Library/Application\ Support/Omogi
      defaults delete com.omogi.mac
5. 권한 목록에서도 지우려면: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 (그리고 캘린더) → Omogi 를 선택하고 "−".
6. 새로 받은 Omogi-Mac.zip 으로 맨 위 "설치"부터 다시 합니다.

 - 0.1.0, 0.1.1 을 쓴 적이 있으면 키체인에 예전 항목이 남아 있습니다. 그대로 둬도 문제없지만, 지우려면
   "키체인 접근" 앱에서 com.omogi.mac 을 검색해 나오는 항목을 지우면 됩니다.


개인정보

 - "친구…"에서 시작하기를 누르기 전에는 서버에 아무것도 보내지 않습니다. O/X 문제는 앱 안에 들어 있고 서버를 쓰지 않습니다.
 - "AI 답변을 기다리는 동안"을 켜면 Enter 를 눌렀는지와 AI 앱의 중지 버튼만 봅니다. 친 글자는 보지도 저장하지도 않습니다.
 - 시작하면 서버에 저장되는 것: 적은 이름, 아이디, 친구 코드, 편지를 잠그는 공개 키, 친구 관계.
   이메일, 전화번호, 비밀번호는 받지 않습니다.
 - 편지 내용은 받는 친구만 열 수 있게 잠가서 보내므로, 서버에서도 만든 사람도 읽을 수 없습니다.
 - 편지는 받는 순간 서버에서 지워지고, 안 받아 간 편지는 14일 뒤에 지워집니다. 잃어버린 편지는 처음부터 저장하지 않습니다.
 - "친구…" 창 아래의 "서버에서 내 정보 지우기"를 누르면 서버의 내 정보가 모두 지워집니다.
 - 받은 편지는 이 Mac 에만 저장됩니다.
