Omogi — 화면에 사는 작은 뱁새 (Windows 판, 테스트 버전 0.1.0)
제작자: @hi20010205

작업 표시줄 위에 흰오목눈이 "오모기"가 살면서 돌아다니고, 졸고, 둥지를 짓습니다.
친구와 쪽지를 주고받을 수 있는데, 오모기가 물고 날아가서 30분~3시간 뒤에 전해 줍니다. 가끔은 잃어버리기도 합니다.
Mac 을 쓰는 친구와도 서로 친구를 맺고 편지를 주고받을 수 있습니다.
의대생이라면 국시 대비 O/X 문제도 풀 수 있습니다 (기초과목 포함 25개 과목, 약 2,800문항).

아직 실제 Windows PC 에서 사람이 써 본 적이 없는 첫 버전입니다. 안 되는 점을 알려 주시면 고칩니다.


설치와 실행

1. Omogi.exe 를 지우지 않을 곳(예: 문서 폴더)에 두고 더블클릭합니다. 설치 과정은 없습니다.
2. "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누른 뒤 "실행"을 누릅니다.
   (서명하지 않은 개인 제작 프로그램이라 뜨는 경고입니다.)
3. 작업 표시줄 위에 오모기가 나타나고, 설정 창이 뜹니다.

Windows 10, 11 에서 동작합니다. 따로 깔아야 하는 것은 없습니다.

설정과 메뉴를 여는 방법은 세 가지이고, 어느 것이든 같습니다.
 - Omogi.exe 를 다시 더블클릭합니다. 설정 창이 뜹니다.
 - 화면의 오모기를 오른쪽 클릭합니다.
 - 작업 표시줄 오른쪽(시계 옆, 안 보이면 ^ 안)의 새 얼굴 아이콘을 오른쪽 클릭합니다. 더블클릭하면 설정 창이 뜹니다.

컴퓨터를 켤 때마다 자동으로 실행하려면 메뉴에서 "Windows 를 켤 때 같이 실행"을 켭니다. (기본은 꺼져 있습니다.)


오모기와 놀기

 - 집어서 옮기기: 오모기를 마우스로 누른 채 끌어다 놓습니다.
 - 던지기: 집은 채로 빠르게 움직이다가 놓으면 날아가서 바닥을 데굴데굴 구릅니다.
 - 가만히 두면 혼자 뛰어다니고, 날아서 옮겨 가고, 졸다가 구르기도 합니다. 5분쯤 컴퓨터를 안 쓰면 둥지를 짓고 잡니다.
 - 습관 알림: 물 마시기(45분), 눈 쉬기(20분), 스트레칭(50분)을 때맞춰 알려 줍니다. 설정 창에서 끌 수 있습니다.
 - 메뉴의 "동작 보기"에서 동작을 하나씩 미리 볼 수 있습니다.


O/X 문제 풀기  (기본은 꺼져 있습니다. 설정 창에서 켭니다)

 - 가끔 물어 오기: 컴퓨터를 쓰는 동안 25분쯤마다 오모기가 문제를 물고 옵니다. 오모기를 살짝 누르면 문제가 펼쳐집니다.
   한참 안 누르면 그냥 내려놓습니다.
 - AI 답변을 기다리는 동안: Claude 나 ChatGPT 의 Windows 앱에서 질문을 쓰고 Enter 를 누르면, 답을 기다리는 동안 화면 위에 문제가 뜹니다.
   답이 도착하면 알아서 접힙니다.
   (브라우저에서 쓰는 claude.ai, chatgpt.com, Gemini 는 아직 안 됩니다.)
 - 지금 한 문제 풀기: 설정 창의 버튼을 누르면 바로 한 문제가 뜹니다.
 - 답하기: O / X 버튼을 누르거나 Alt+O / Alt+X.
 - 과목 고르기: 설정 창의 "O/X 과목 고르기…"에서 풀 과목만 켭니다.
 - 내 문제 넣기: 메뉴 → "내 문제 편집…" (저장한 뒤 "내 문제 다시 읽기")
 - 연속으로 맞히면 오모기가 점점 커집니다. 다섯 번 연속이면… 직접 해 보세요.
 - Loading Dose 를 같이 쓰고 있으면 "AI 답변을 기다리는 동안" 카드는 Loading Dose 쪽에서만 뜹니다.
 - 문항은 사람이 하나하나 검수한 것이 아닙니다. 틀린 곳이 보이면 알려 주세요.


편지

 - 설정 창의 "친구…"에서 이름과 아이디를 정하고 시작합니다. 내 아이디나 친구 코드를 친구에게 알려 주면, 친구가 그것으로 친구 신청을 합니다.
 - Mac 판을 쓰는 친구와도 똑같이 친구를 맺고 편지를 주고받습니다.
 - "편지 쓰기…"로 쪽지를 쓰면 오모기가 물고 날아갑니다. 30분~3시간 뒤에 도착하고, 100통에 8통쯤은 가는 길에 잃어버립니다.
 - 편지가 오면 오모기가 편지를 물고 기다립니다. 오모기를 살짝 누르면 편지함이 열립니다.
 - 서버 없이 혼자 해 보고 싶으면 받는 사람에서 연습 상대를 고르면 됩니다.


알아 둘 점

 - 편지 내용은 내 컴퓨터에서 잠근 뒤에 보내고, 받는 친구의 컴퓨터에서만 열립니다. 서버에는 잠긴 채로만 지나갑니다.
 - "AI 답변을 기다리는 동안"을 켜면 Enter 키를 눌렀는지와 Claude·ChatGPT 앱 화면의 버튼 이름("중지" 버튼이 있는지)만 읽습니다.
   친 글자나 대화 내용은 읽지도 저장하지도 않습니다. 꺼 두면 키 입력을 전혀 보지 않습니다 (카드가 떠 있는 동안의 Alt+O / Alt+X 는 예외).
 - 설정, 푼 기록, 받은 편지는 내 컴퓨터의 %APPDATA%\Omogi 폴더에만 저장됩니다.
 - Mac 판에 있는 집중 모드(유튜브·인스타그램 탭 닫기)와 일정 알림은 Windows 판에 아직 없습니다.


지우기

1. 메뉴에서 "Windows 를 켤 때 같이 실행"을 켜 두었다면 먼저 끕니다.
2. 메뉴나 설정 창에서 "Omogi 종료"를 누릅니다.
3. Omogi.exe 를 지웁니다.
4. 기록까지 지우려면 파일 탐색기 주소 칸에 %APPDATA% 를 치고 들어가 Omogi 폴더를 지웁니다.
   (이 폴더를 지우면 아이디와 친구, 받은 편지도 사라집니다. 서버의 계정까지 없애려면 지우기 전에 "친구…" 창에서 서버를 떠나세요.)


잘 안 될 때 보내 주실 것

 - 오모기를 오른쪽 클릭(또는 트레이 아이콘 오른쪽 클릭) → "진단 정보 복사"를 누르고 붙여넣어 보내 주세요.
   보내기 전에 내용을 한 번 확인하세요. 대화나 편지 내용은 들어가지 않습니다.
 - "진단 기록 파일 열기"로 열리는 파일도 함께 보내 주시면 더 좋습니다.
