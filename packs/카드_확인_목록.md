# Allen Cloze 카드 확인 목록

기본 제공 퀴즈를 만들면서 문항으로 쓰지 않고 넘긴 카드 주제입니다. 과목별 에이전트가 "카드 내용이 통용되는 기준과 다르다"고 보고한 것을 모았습니다. 에이전트의 판단이 틀렸을 수도 있으니, 고치기 전에 교재나 가이드라인으로 확인하세요.

## 오기나 오류로 보이는 카드

| 과목 | 카드 내용 | 문제 |
|---|---|---|
| 소화기, 외과 각론 | HCC 종양표지자 AFP ≥ 400 ng/dL | 단위는 보통 ng/mL |
| 외과 각론 | 장회전이상 꼬임의 조영 소견 = coiled spring | 전형적 소견은 corkscrew. coiled spring은 보통 장중첩증 |
| 외과 각론 | ER(+) 유방암 폐경 전 SERM에 raloxifene 포함 | raloxifene은 폐경 전 치료제로 쓰지 않음 |
| 소화기 | 바렛 식도의 10%에서 선암 발생 | 실제 위험은 연 0.1~0.5% 수준 |
| 소아 총론 | 비타민 A 결핍 혈장 retinol < 20 μg/mL | μg/dL의 오기로 보임 |
| 소아 총론 | 카페오레 반점 "1 cm 이상 6개" | NF1 기준(사춘기 전 5 mm, 후 15 mm)과 다르고 카드 해설과도 불일치 |
| 신장 | ADPKD 영상 기준 "30~59세 양쪽 각각 2개 이상" | 30~39세는 총 3개 이상, 40~59세가 양쪽 각각 2개 이상 |
| 산과 | 태반조기박리 초음파 = hypoechoic 혈종 | 급성기 혈종은 hyper~isoechoic, 시간이 지나야 hypoechoic |
| 종양 | "항암 단독으로 완치 가능한 암"에 SCLC 포함 | SCLC는 제한기에서도 완치가 드묾 |
| 예방의학 | (노출군−비노출군)/노출군을 "기여위험도"로 표기 | 교재에 따라 이것은 기여위험분율이고, 기여위험도는 위험도 차이 |
| 정신건강의학과 | 아캄프로세이트를 "효현제 유지요법"으로 분류 | 기전 분류가 부정확 |

## 카드끼리 서로 다른 내용

| 과목 | 내용 |
|---|---|
| 알레르기 | 면역치료가 음식 알레르기에 효과 없다는 카드 ↔ 소아 땅콩·밀·계란 경구면역치료가 가능하다는 카드 |
| 정신건강의학과 | 항우울제 효과 발현 "3~5주 후" ↔ "2주 후부터 반응" |
| 부인과 | PCOS 배란유도 1차가 letrozole 단독 ↔ clomiphene과 letrozole 병기 |
| 의료법규 | 특정수혈부작용 신고 대상이 시·도지사 ↔ 보건소장을 거쳐 시·도지사 |

## 최신 지침과 달라 보이는 카드

- **순환기·응급(마이너)**: 심정지 후 목표체온 32~36℃(최근은 발열 방지 위주), 둘째 제세동 실패 후 amiodarone(통상 셋째 이후), aSAH 혈압 목표, SAH 후 triple-H 요법
- **감염**: HIV 확진 = Western blot, 호중구감소성 발열 ANC <1500, ABPA 1차 = itraconazole, 대상포진 생백신, VZIG 96시간 이내
- **호흡기**: 원발성 자연기흉 치료 방침(ACCP 2001 기준), 폐색전증에서 혈전용해 금기 시 수술적 색전제거술 1차
- **내분비**: DKA에서 insulin 전 K⁺ 기준 3.5(ADA 3.3), HHS 삼투압 >330(ADA >320), 임신 중 levothyroxine 50% 증량, T1DM 신장병증 선별 시점
- **혈액**: NK/T세포 림프종 초기 방사선 단독, vitamin K 결핍 출혈에 재조합 VIIa, cobalamin 경구 흡수 불가, "CRAB 없으면 MM 아님", ITP 혈소판 수혈 금기
- **류마티스**: 급성 통풍 발작 중 요산 저하 치료 시작 금지
- **신장**: CKD 목표 혈압, 고칼륨혈증 정의 >5.5
- **외과 총론**: Parkland 공식 4 mL(최신 ATLS는 성인 2 mL), 긴장성 기흉 바늘감압 2번째 늑간, DES 후 DAPT 365일, 와파린 출혈에 FFP, 패혈성 쇼크 CVP >8 목표
- **외과 각론**: MCN·IPMN 모두 췌장절제, 간 단순낭종 흡인 후 경화제
- **산과**: FGR 도플러별 분만 시점, GDM 1차 약물
- **부인과**: Turner 증후군 estrogen 시작 시기, 근종 ulipristal, AIS 치료
- **소아청소년과 각론**: 천식 reliever = SABA, 백일해 1차 erythromycin, 열성 경련 정의 39℃, 5세 미만 결핵 접촉자 TST 우선, palivizumab 적응증
- **소아청소년과 총론**: Wilson병 1차 chelator, 사시 정상 기간 6개월
- **정신건강의학과**: 지연성 운동이상증 치료 = clozapine, 틱장애 1차 = 항정신병약물, 뇌진탕후 증후군 3개월 기준
- **마이너**: 비출혈 1차 = silver nitrate 소작, 영아혈관종 = 경과관찰, 급성 중이염 중증 38.5℃, 삼출성 중이염 환기관 4개월, 진균 각막궤양 항진균제, 급성 SDH 개두술 적응증 조합
- **의료법규**: 면허 재교부 제한 기간, 마약류관리자 지정 주체, 외국인 장기체류자 HIV 음성확인서, 보건소장 임용 자격 (개정 여부 확인 필요)

## 원자료에 없어 문항이 빠진 주제

- **예방의학**: 예측도(PPV·NPV), 상대위험도·교차비 해석, 발생률과 유병률의 관계, 교란 통제 방법. 과목당 260장 안팎만 추려 넣었기 때문에 전체 덱에는 있을 수 있습니다.
